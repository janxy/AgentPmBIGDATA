# 海上全域感知大屏 - 智能执法模块设计方案 v1.1

## 1. 背景与目标

大屏顶部新增“智能执法”入口，以弹层承载执法派单展示。模块保持轻量：

1. 提供“当前派单”与“历史派单”两个只读列表。
2. 与顶部入口、大屏缩放保持一致，所有数据来自前端 mock。
3. 不引入派单操作、筛选、详情联动等复杂交互。

## 2. 功能范围

### 2.1 当前派单

- 展示执行中与待执行的派单。
- 列：派单编号、告警类型、目标名称、执法船、派单时间、状态。
- 状态：待出航 / 出航中 / 已抵达 / 处置中。

### 2.2 历史派单

- 展示已结束的派单。
- 列：派单编号、告警类型、目标名称、执法船、派单时间、处置结果。
- 结果：处置完成 / 超时未处置 / 转办。

## 3. 信息架构与交互

```
智能执法弹层
├── 标题栏：智能执法 / 当前派单数 · 历史派单数 / 关闭
└── Tab：当前派单 | 历史派单
    └── 派单列表（只读）
```

交互流程：

1. 点击顶部“智能执法”打开弹层，默认显示当前派单。
2. 切换 Tab 查看历史派单。
3. 点击关闭或弹层空白区域退出。

## 4. 数据模型

派单数据包含：派单编号、告警类型、告警等级、目标名称、执法船名称、派单时间、派单状态、处置结果、结束时间等字段，统一由 mock 内存数据提供。

## 5. 接口设计

| 接口 | 方法 | 说明 |
| --- | --- | --- |
| /api/maritime/law/orders | GET | 派单列表，前端按状态区分当前/历史 |
